# El. Laiškų Rašymas

Parašykite profesionalų, paruoštą siųsti el. laišką bet kokiai situacijai. Pateikite kontekstą — kam rašote, apie ką ir kokiu tonu — ir gausite paruoštą el. laišką, kurį galite kopijuoti arba koreguoti.

## Instrukcijos

### 1 žingsnis: Suprasti situaciją

Iš vartotojo užklausos nustatykite:

- **Gavėjas** — Kam šis laiškas skirtas? (klientas, viršininkas, potencialus klientas, tiekėjas, komanda, nepažįstamas žmogus)
- **Tikslas** — Koks tikslas? (prisistatyti, priminti, derėtis, atnaujinti informaciją, paprašyti kažko, atsakyti neigiamai)
- **Tonas** — Formalus, profesionalus-neformalus, draugiškas, tvirtas, atsiprašantis, entuziastingas?
- **Pagrindiniai punktai** — Kas BŪTINAI turi būti pasakyta?
- **Santykių kontekstas** — Pirmas kontaktas? Ilgalaikiai santykiai? Atsakymas į kažką?

Jei vartotojo užklausa pakankamai aiški, rašykite laišką nedelsiant. Klausimų užduokite tik tuo atveju, jei trūksta svarbios informacijos (pvz., kam laiškas skirtas arba apie ką jis).

Patikrinkite CLAUDE.md, jei jame yra vartotojo vardas, pareigos ir bendravimo stilius.

### 2 žingsnis: Parašyti laišką

**Struktūra:**

```
Subject: [Aiški, konkreti tema — ne bendro pobūdžio]

[Pasveikinimas — atitinkantis santykius: "Sveiki, Sarah," / "Gerbiamas pone Chen," / "Labas, komanda,"]

[Įžanginė eilutė — kontekstas ar sąsaja. Niekada nepradėkite žodžiais "Tikiuosi, šis laiškas jus randa gerai." Vietoj to paminėkite kažką konkretaus: jų pastarąjį darbą, bendrą pažintį arba tiesiog perkite prie esmės.]

[Pagrindinė dalis — ne daugiau kaip 2-4 trumpos pastraipos. Viena mintis vienoje pastraipoje. Pradėkite nuo svarbiausio.]

[Aiškus prašymas ar kitas žingsnis — ką norite, kad jie padarytų perskaitę šį laišką?]

[Atsisveikinimas — atitinkantis toną: "Pagarbiai," / "Dėkoju," / "Lauksiu jūsų atsakymo,"]
[Vartotojo vardas]
```

### 3 žingsnis: El. laiškų tipų šablonai

Naudokite tinkamą struktūrą pagal laiško tipą:

| Tipas | Pagrindiniai elementai |
|------|-------------|
| **Šaltas kontaktas** | Pradėkite nuo vertės/aktualumo, ne nuo savęs. Kodėl jiems turėtų rūpėti? Vienas aiškus kvietimas veikti. |
| **Priminimas** | Paminėkite ankstesnę sąveiką. Pridėkite naujos vertės, ne tik „pasiteiraukite, kaip sekasi". |
| **Derybos** | Aiškiai išdėstykite savo poziciją. Naudokite „Norėčiau pasiūlyti", ne „Galvojau, ar galbūt." |
| **Atnaujinimas/būsena** | Pradėkite nuo svarbiausios žinios. Detales pateikite žemiau. Užbaikite kitais žingsniais. |
| **Atsakymas neigiamai** | Būkite tiesūs ir malonūs. Trumpai paaiškinkite priežastį. Jei galima, pasiūlykite alternatyvą. |
| **Prisistatymas** | Kas esate (1 sakinys), kodėl rašote (1 sakinys), ko prašote (1 sakinys). |
| **Padėka** | Konkrečiai įvardinkite, už ką dėkojate. Nebūkite bendro pobūdžio. |
| **Atsiprašymas** | Pripažinkite, kas atsitiko, prisiimkite atsakomybę, nurodykite, ką darote dėl to. Be pasiteisinimų. |
| **Prašymas** | Iš anksto pasakykite prašymą. Trumpai paaiškinkite kodėl. Padarykite, kad jiems būtų lengva sutikti. |

### 4 žingsnis: Kokybės taisyklės

| Taisyklė | Kodėl |
|------|-----|
| Temos eilutė turi būti konkreti | „Q1 biudžeto pasiūlymas — peržiūrėti iki penktadienio", o ne „Priminimas" |
| Pirmas sakinys turi „užkabinti" antrą | Jei įžanga nuobodi, žmonės nustoja skaityti |
| Maksimaliai 5 sakiniai pastraipoje | Teksto sienų niekas neskaito |
| Vienas aiškus kvietimas veikti | Neverskite spėlioti, ko norite |
| Be tuščiažodžių frazių | Pašalinkite „Tiesiog norėjau," „Galvojau, ar," „Tikiuosi, šis laiškas jus randa gerai" |
| Atitikite jų energiją | Jei jie parašė 3 sakinius, nerašykite 3 pastraipų |
| Perskaitykite kritiškai | Perskaitykite kaip gavėjas. Ar skamba įkyriai? Pasyviai? Neaiškiai? |

### 5 žingsnis: Pateikti variantus

Parodykite laišką ir pasiūlykite:
- „Norite, kad padaryčiau trumpesnį / ilgesnį / formalesnį / neformalesnį?"
- „Norite kitos versijos su kitokiu požiūriu?"
- „Ar turėčiau parašyti priminimo laišką, jei jie neatsakys per [X] dienų?"

## Rezultatas

Pilnai paruoštas siųsti el. laiškas su temos eilute. Švarus tekstas, kurį vartotojas gali tiesiog nukopijuoti į savo el. pašto programą.
